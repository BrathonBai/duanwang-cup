## 一句话故事
最后一台路由器拔掉了自己的电源，人类退回史前变成恐龙；但局域网还在，于是他们在没有网的会议室里办了一届「断网杯」，用手机当手柄跑 1024 米，许愿、被淹、上车、打王。最后发现：路由器一直就在桌上。

## 声音设计
- **BGM**：5 段 numpy 合成芯片音乐，按段落切换：epic（断网史诗）→ end（局域网 / 片尾）→ race（规则、竞速、许愿、Roadster）→ ad（水世界广告）→ boss（Boss 战）→ end（反转与片尾）；全部 48kHz，可复现（`_pv/audio/gen_audio.py`）。
- **音效**：拔电源、鞭响、金币、玻璃碎裂、水花、1.76kHz 消音哔、喷气、撞击、打王、掌声等 15 个（`_pv/audio/sfx/`）。
- **整体**：−14.6 LUFS / −1.0 dBTP；字幕卡与画面同步由 `_pv/make_pv.py` 自动合成。

## 制作说明
- 画面：7 段真实游戏实机录屏（1600×900 canvas → 1920×1080）+ 10 张 PIL 绘制卡片 + 3 张实机截图，`_pv/make_pv.py` 统一时间线合成。
- 字幕：PIL 渲染为透明 PNG 叠加，带淡入淡出；滚动新闻条用 overlay 位移表达式实现。
- 重跑：`python _pv/make_pv.py`（需要 `_pv/gameplay.mp4` 与 `_pv/audio/`，卡片由 `python _pv/cards.py && python _pv/extra_cards.py` 生成）。
