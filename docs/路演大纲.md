# 《断网杯》路演大纲

> 你手上的牌：**一支 2:01 的 PV + 一个能现场跑的游戏**。这份大纲只围绕这两样组织，不讲代码。
> 默认按 **3 分钟**写；5 分钟 / 8 分钟 / 90 秒版在后面。

---

## 0. 上台前 90 秒 checklist

- [ ] 游戏服务已在跑：`node server.js`，大屏 `http://localhost:3000`，先**用鼠标点一下页面**（解锁解说 TTS）
- [ ] 浏览器两个标签：① `pv-v2.mp4`（本地全屏，音量 80%）② 游戏大屏（F11 全屏）
- [ ] 关掉微信/系统通知；投影/镜像已确认；任务栏自动隐藏
- [ ] 手机（可选）：2 台已连同一 Wi-Fi，提前打开 `/pad` 入场页；热点叫「断网杯-请勿连接」
- [ ] 如果大厅里残留上一局：按 `Esc` 或点「返回开始页」
- [ ] 记牢：`Space` 开始/跳 · `W` 许愿 · `T` 水世界 · `R` 发车钥匙 · `F` 起飞 · `B` 直接 Boss

> 现场网络真的会断。所以：**手机连不上就用键盘入场，别修网。**

## 1. 3 分钟逐字稿（默认版）

### 0:00–0:15 开场钩子（不看屏幕，看观众）

> "大家好，我们是断网杯。
> 我先问一句：**如果现在把网断了，这屋子里还能发生什么？**
> 我们的答案是——办一场比赛。"

### 0:15–0:55 放 PV（只放前 41 秒）

- 播放 `pv-v2.mp4` 到 **0:41.7**（"LAN RULES / 局域网规则"那张卡念完、还没进竞速）**立刻暂停**
- 播放时站到屏幕侧边，**别说话**，让字幕和音乐自己讲
- 切回游戏窗口，第一句：

> "片子里是预录的。这一局，我们现场开。"

### 0:55–2:20 现场演示（约 85 秒）

| 时间 | 动作 | 台词 |
|---|---|---|
| 0:55 | 回到大厅，指二维码 | "一台笔记本就是服务器；手机扫码就是手柄。" |
| 1:00 | 点「⌨ 键盘入场」×2，点「+ 加一个机器人」，按 `Space` | "没带手机的同学，键盘也能上，机器人陪跑。" |
| 1:10 | 起跑后按 `Space` 跳、`Shift` 冲刺 | "手感是专门调的——按键立刻有反馈。" |
| 1:20 | 按 `W`，输入「给第一名来一根仙人掌」回车；再来一句「全场下金币雨」 | "现场可以许愿。**一句话，就能改变比赛**。它不联网，纯本地规则，断网也能用。" |
| 1:38 | 按 `T` | "路被淹了。**比赛没有暂停**。" |
| 1:48 | 按 `R`，停半拍，按 `F` | "注意，后半程会出现一辆不该出现的车。没时间解释了，快上车。" |
| 2:05 | 等车撞王 / 按 `B` | "1024 米之后，没有奖杯，只有终极仙人掌王。" |
| 2:15 | 切回桌面或停在大屏 | "一局两分钟。**现场办一场，只要一条命令。**" |

### 2:20–2:55 不上代码，讲三个取舍

1. **为什么手机当手柄**：不用装 App，扫码就玩；大屏负责公共叙事，手机负责私密反馈（震动、红晕、被整提示）。
2. **为什么许愿不用大模型**：这是断网杯，网是真的会断；本地规则解析延迟 <1ms、结果可控。真接 LLM 也只换解析器，游戏层不动。
3. **为什么能现场办**：零 npm 依赖、二维码页面内置、一条命令开赛。**它不是"视频里的游戏"。**

### 2:55–3:00 收尾金句（选一句）

> "断网杯不是把网断掉的游戏，是**把'没有网'当成设计前提**的游戏。"
> "如果今天现场网又断了——没关系，我们本来就没打算连。"
> "欢迎扫码，跟我们一起跑一局。"

## 4. Q&A 小抄（每题 20–30 秒）

| 问题 | 回答 |
|---|---|
| 这是什么类型？ | 局域网派对跑酷。一台笔记本当服务器，大屏当赛道，手机当手柄，8 人同屏。 |
| AI 在哪里？ | **许愿式交互**：一句自然语言 → 游戏事件（点名/全场/第一名 + 仙人掌/金币雨/打王）。解析器是离线规则引擎，刻意不依赖模型；要接 LLM 只换 `wish.js`。 |
| 为什么叫断网杯？ | 断网不是故障，是设定。所有能力都在本地，现场网断了反而更能说明问题。 |
| 和 Chrome 断网恐龙什么关系？ | 素材致敬官方精灵；我们把它做成多人同屏 + 直播解说 + 许愿 + Boss 战。 |
| 最难的是什么？ | 两个：一句话的歧义（谁、什么效果、多少），和现场网络。我们用目标剥离 + 意图表 + 三层网络保险解决。 |
| 完成度？ | 5 个自测脚本，大屏/手机/观众席三条链路都在真实 Chrome 跑过，零 npm 依赖。 |
| 商业化/场景？ | 团建、展会、校园活动、Livehouse 暖场；品牌可定制（广告牌、载具、解说词都是现成梗）。 |
| 下一步？ | 手机弱网优化、更多小游戏/道具、把许愿接 LLM 作为可选模式、做赛事化（排行榜/回放）。 |

## 5. 事故预案（背下来，别慌）

| 事故 | 一句话 + 动作 |
|---|---|
| 手机连不上 / 扫码没反应 | 直接点「⌨ 键盘入场」："现场网络果然又断了——这正是我们的主场。" |
| 没有声音 | 鼠标点一下大屏；还不行就继续讲，PV 有字幕。 |
| PV 播不出来 | 直接开游戏，用 `T` / `R`+`F` / `B` 演三个亮点。 |
| 游戏崩了/白屏 | 切回 PV 或截图，说"这就是断网的下场"；重启 server 只要 1 秒。 |
| 按 `B` 没反应 | 说明不在比赛中（倒计时/结算），等 2 秒再按。 |
| 被评委问住 | 回到三句：断网也能玩；一句话改变比赛；一条命令开赛。 |
