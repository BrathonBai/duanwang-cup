## 一、作品说明（可直接粘贴）

### 正式版（约 900 字，优先用这版）

断网杯是一款为「断网现场」设计的局域网派对跑酷：一台笔记本开着 Node 服务就是赛道，手机扫码就是手柄，一屋子人挤在同一条赛道上跑到 1024 米，再一起围殴终极仙人掌王。它不依赖公网，也没有任何 npm 依赖——`node server.js` 之后，断网也能开赛。

【使用方式】
1. 笔记本运行 `node server.js`，大屏打开 `http://localhost:3000`，大厅自带二维码与局域网地址；
2. 手机连同一个 Wi-Fi 扫码入场（不想掏手机可点「键盘入场」，一个人加两个机器人也能演示）；横屏即全屏赛道，左下冲刺/下蹲、右下跳；
3. 跑到 1024 米进入 Boss 战，全队用跳、下蹲、冲刺投掷奇怪物件打王；
4. 现场许愿：大屏按 `W`，或手机打开 `/wish`，输入一句中文就能改变比赛（如「给第一名来一根仙人掌」「全场下金币雨」「给老王回血」）；
5. 观众/裁判打开 `/background` 多机位分屏观战。手机入场可选三套皮肤：经典像素恐龙、深蓝女仆、橙发女仆。

【亮点】
- **断网可玩**：二维码由页面内置生成，许愿解析是手写离线中文规则（`wish.js`），不调大模型、不请求外网；0 个 npm 依赖，一条命令开赛。
- **一块屏叙事、一块屏操作**：大屏负责解说、排行榜、Boss 与许愿横幅；手机负责私密反馈（震动、红晕、被整提示），弱网也不飘。
- **许愿式编程的现场版**：一句话 → 目标识别（点名/全场/我/第一名/随机）+ 意图匹配（仙人掌/金币雨/减速/回血/打王…）+ 数值提取，延迟 <1ms、结果可预期；每人 5 秒冷却，比赛外不许愿。
- **手感与服务端权威**：60Hz 权威模拟、输入队列、跳跃缓冲、命中停顿、屏幕震动；客户端改不了结果。
- **荒诞分段**：560–700 米被淹的「疯狂水世界」、会喷气起飞的 Tesla Roadster、1024 米后的终极仙人掌王，都是独立玩法段落，不是换皮。

【实现思路】
- **架构**：纯 Node.js（http + SSE）单进程房间，服务端 60Hz 权威模拟；大屏、手机、观众席共用一条 SSE 广播，手机上只上报输入。
- **渲染**：Canvas 2D；经典恐龙切片自 Chrome 断网页官方精灵，另有两套像素角色皮肤（深蓝女仆 / 橙发女仆）；文字、动效全部矢量绘制。
- **许愿解析**：分词 → 目标剥离 → 意图表 → 数值正则，纯本地；冷却与节流在服务端，非 Boss 战的「打王」不生效。
- **局域网**：启动时探测并打印局域网 IP，二维码用内置 qrcode-generator 在浏览器里画，零外部命令。
- **质量**：5 个自测脚本（许愿解析单测、HTTP 冒烟、特性联调、许愿接口联调、无头浏览器 E2E），大屏 / 手机两条主流程已在真实 Chrome 跑通。

### 短版（约 280 字，表单有字数限制时用）

断网杯是一款「大屏当赛道、手机当手柄」的局域网派对跑酷：一台笔记本 `node server.js`，手机扫码即玩，最多 8 人同屏；跑到 1024 米后全队一起打终极仙人掌王。它真的不联网——二维码由页面内置生成，许愿解析是手写离线中文规则：大屏按 `W` 或打开 `/wish`，一句「给第一名来一根仙人掌」就能立刻改变比赛。路上还有被淹的疯狂水世界、会喷气起飞的 Tesla Roadster 和会掉血的创可贴恐龙。服务端 60Hz 权威模拟，零 npm 依赖，一条命令开赛，现场不慌。

## 三、作品形式（三选一）

**建议选「上传视频文件」。**

理由：这是一个现场局域网游戏，评委无法直接扫码进场；视频能在 30 秒内把「手机手柄 + 同屏 + 打王 + 许愿 + 喷气起飞」全部讲清楚。

| 选项 | 建议 | 用哪个文件 / 说明 |
|---|---|---|
| ✅ 上传视频文件 | **首选** | `docs/pv-v2.mp4`（16:9，**2 分 01 秒**，1920×1080，中文大字幕 + 芯片音乐 + 音效，26 MB）。故事版已包含许愿池 / 疯狂水世界 / Roadster / Boss / 反转结局。旧版 `docs/pv.mp4`（63 秒）与 `docs/pv-25s.mp4`（24.8 秒）保留作短版备选。 |
| 上传网页文件 | 备选 | 用刚打包的 `docs/断网杯-网页文件.zip`：解压后 `node server.js`（无需 `npm install`），大屏 `http://localhost:3000`，手机同 Wi-Fi 扫码。适合平台会运行/托管网页作品的情况。 |
| 在线链接 | 不选 | 项目没有公网部署（现场靠局域网），填链接反而会让评委打不开，不建议。 |
