## 设定

一场断网事故，让人类退回史前，变成了小恐龙。
但他们没有忘记局域网——于是，一群恐龙在赛道上狂奔，试图把彼此连起来。

## 声音

- 旁白：史诗段用 Li-mu（低沉男声）；反转后切回游戏里的婷婷。
- BGM：Python + numpy 合成的芯片音乐（方波主旋律 / 三角波贝斯 / 噪声鼓），A 小调，片尾转滑稽小调。
- 音效：三次特写切镜各一记鞭响；撞车一记 44Hz 低频。
- 反转点：音乐**硬切静音**，只留下现实的声音。

## 制作

- 画面：无头 Chrome 录真实游戏（CDP screencast），不是后期动画。
- 特写：从游戏画面裁切 170–400px 区域，最近邻放大到 1080p，保留像素颗粒。
- 片头/片尾/职员表：HTML 或 PIL 渲染，字体与游戏一致。
- 全部素材自产，无版权问题。
