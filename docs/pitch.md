# 断网杯 · 路演稿（3 分钟版）

> 题目：**游戏 · 断网后的奔跑，是赛博朋克的浪漫与黑色幽默**（我们自己写的题）
> 用途：hackathon 现场演示 / 评委问答。30 秒版在最前面，后面是结构与问答。
> 原则：只讲能现场演出来的东西；不把规则解析说成大模型。

## 30 秒版

「网络断了。直播还在。
这是一个『断网之后，大家挤在一条赛道上继续跑』的派对游戏。

大屏是赛道，手机是手柄，1024 米后打仙人掌王。
选手能选三种形象：Chrome 断网像素恐龙、Deepseek Chan 深蓝女仆、橙发女仆——全部 64 位像素精灵。
路上你会遇到被淹的**疯狂水世界**——所有人踩着水继续跑，
还能捡到海水过滤器、电鳗发电机、刺豚制氧机这三件离谱道具；
还会捡到一辆会喷气起飞的 **Tesla Roadster**，从天上落下来，把全队带上，撞进王的脸。

而且它真的**不联网**。许愿解析是本地手写规则，断网也能用。
因为 1024 的现场，网可能真的会断。」

## 题解：为什么是「赛博朋克 + 黑色幽默」

- **赛博朋克**：大屏是断网后临时搭起的广播，解说一个人对着空场继续播；手机是手柄，也是每个人仅剩的屏幕；一辆会喷气的 Roadster 是「技术废墟里的浪漫」。
- **黑色幽默**：所有人都在认真比赛，但规则和解说都在摆烂——成就是「第一名（倒数）」「躺平先锋」，路被淹了不暂停，广告牌还在喊「开局一定要选海水过滤器」。
- **断网**：不是限制，是设定。所有能力都在本地，反而让「许愿」和「整活」更快。

## 3 分钟结构

### 0:00–0:30 钩子

- 今天是程序员节，也是「人类最后一届」的段子。
- 今年最热的能力是许愿式编程：一句人话 → 一个可运行的东西。
- 我们想问：**如果许愿对象不是代码，而是正在进行的比赛呢？**
- 再加一个前提：**网断了。** 断网之后，人还得跑。

### 0:30–1:30 现场演示（不讲解，先让观众看到）

1. 大屏大厅，两部手机扫码入场（或键盘入场），开局。
2. 按 `W`，输入「给第一名来一根仙人掌」。
   - 大屏横幅：许愿内容 + 解说回复；
   - 第一名真的被扎，血量 -1。
3. 再按 `W`，输入「全场下金币雨」。
   - 满地下金币，选手边跑边捡。
4. 切到「✨ 许愿」二维码，请一位评委用手机点「按钮失灵」。
   - 全场手机按钮变成「提交」，3 秒后恢复。
5. 按 `T` 直接跳到 600 米：**疯狂水世界**。
   - 水面、波纹、广告牌、「疯狂水世界，启动！」横幅。
   - 顺手捡海水过滤器 / 电鳗发电机 / 刺豚制氧机，展示三种效果。
6. 按 `R` 发 Roadster 钥匙，再按 `F`：
   - 车从天而降 → 全员上车 → 喷气起飞 → 俯冲撞王。
7. （可选）按 `B` 直接进 Boss，许愿「王掉 20 血」。

### 1:30–2:20 技术拆解（三句话）

- **一句话怎么变成效果**：`wish.js` 做目标识别（点名/全场/我/第一名/随机）+ 意图匹配（仙人掌/金币/减速/打王…）+ 数值提取；纯本地、零依赖。
- **为什么不用大模型**：这是断网杯，现场可能没网；规则解析延迟 <1ms、结果可预期、不会被模型胡说带偏。这是一个**刻意的工程取舍**，不是能力缺失。
- **为什么手感稳**：服务端 60Hz 权威模拟、输入队列、跳跃缓冲、命中停顿；手机只是显示器 + 手柄，弱网也不飘。

### 2:20–3:00 收束

- 这不是一个「演示视频里的游戏」，是一个**现场能办起来**的游戏：
  零 npm 依赖、一条 `node server.js`、二维码页面内置、手机连 Wi-Fi 就能玩。
- 断网杯的「断网」不是限制，是设计前提：
  所有能力都在本地，反而让「许愿」这件事变得更快、更可控。
- 一句话：**把许愿式编程，从屏幕里拿出来，变成一屋子人能一起玩的东西。**

## 评委可能问的问题

**Q：这算 AI 吗？**
A：许愿交互是 AI 产品的典型形态，但我们的解析器是规则引擎，故意不依赖模型。现场断网也能用，延迟和结果都可控。如果要接 LLM，接口已经隔离在 `wish.js`，换掉解析器即可，游戏层不用动。

**Q：为什么手机当手柄，而不是直接网页玩？**
A：手机竖屏是「手柄」，横屏是「第一人称赛道」；大屏负责公共叙事（解说、排行榜、Boss），手机负责私密反馈（震动、红晕、被整提示）。两块屏各干各的，现场更像比赛。

**Q：多人会不会乱？**
A：目标解析支持点名/全场/我/第一名/随机；许愿有 5 秒/人冷却和全场节流；整蛊和许愿都走同一套服务端权威逻辑，客户端改不了结果。

**Q：断网怎么保证二维码能用？**
A：二维码由页面内置的 qrcode-generator 在浏览器里画，不调用系统 `qrencode`，也不请求外网。局域网 IP 会自动避开 VMware/WSL 虚拟网卡。

**Q：为什么突然加一辆会飞的车和一段水上跑？**
A：这是「黑色幽默」的部分：现实已经很不讲道理了，游戏里也要有荒诞的意外。Roadster 是技术废墟里的浪漫，疯狂水世界是国产手游广告梗——路被淹了，比赛不暂停，广告牌还在喊「开局一定要选海水过滤器」。它们都不是换皮，是独立的玩法段落。

**Q：最难的部分？**
A：不是画面，是「一句话的歧义」和「现场网络」。比如「让老王掉血」既可能指玩家也可能指王；我们把目标名字先从文本里剥掉，再匹配意图，并在非 Boss 战拒绝打王。现场网络则用 IP 探测 + 二维码 + 键盘兜底三层保险。
